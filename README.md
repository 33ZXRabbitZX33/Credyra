# Credyra

Bảng điều khiển quản lý tài chính cá nhân (thẻ tín dụng, khoản vay trả góp, ví, giao dịch) — một trang HTML tĩnh, dữ liệu lưu trong `localStorage` của trình duyệt.

## Chạy thử

Mở trực tiếp [`index.html`](index.html) trong trình duyệt, hoặc dùng bất kỳ static server nào:

```bash
npx serve .
```

## Deploy (GitHub Pages)

Repo này chỉ cần host tĩnh, không có bước build:

1. Vào **Settings → Pages**.
2. Ở mục **Build and deployment → Source**, chọn **Deploy from a branch**.
3. Chọn branch `main`, thư mục `/ (root)`, rồi **Save**.
4. Sau vài phút, trang sẽ có tại `https://33ZXRabbitZX33.github.io/Credyra/`.
